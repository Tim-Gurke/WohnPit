# Historische Watt’n’Pit-Versionshistorie

**Watt’n’Pit und die bisherige WohnPit-Zentrale sind in WohnPit zusammengeführt.** Diese Vorgeschichte bleibt öffentlich erhalten; aktuelle Downloads und die gemeinsame Weiterentwicklung stehen im [WohnPit-Hauptprojekt](../../README.md). [Herkunft und Archivhinweise](HERKUNFT.md).
