# Historische Watt’n’Pit-Dokumentation

Diese Dokumentation stammt aus dem früher öffentlichen Watt’n’Pit-Repository, Quellstand `8dd3cecd5d6050354037ccf04150b087d2efb81e`. Sie bleibt als vollständige dokumentierte Vorgeschichte öffentlich erreichbar. Watt’n’Pit und die bisherige WohnPit-Zentrale sind in **WohnPit** zusammengeführt. Die Weiterentwicklung und aktuelle APKs stehen im [WohnPit-Hauptprojekt](../../README.md).

Die folgenden Seiten beschreiben damalige Versionsstände und Prüfgrenzen. Historische Downloadlinks sind keine Empfehlung für eine Neuinstallation. Für Installation und Updates die [aktuelle WohnPit-Anleitung](../ZUSAMMENFUEHRUNG.md) verwenden. Das bisherige Watt’n’Pit-Repository wird privat weiter aufbewahrt.
